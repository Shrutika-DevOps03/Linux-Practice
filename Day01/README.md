ls -la                # List with permissions and extra information
cd ..                 # Go to parent directory

## Absolute path vs Relative path 

- Absolute path : Always starts from the root directory(/), making it a complete address that work from anywhere in the system.
- Relative path : Starts from your current working directory, making it a shortcut based on where you are currently "standing" in the terminal.
